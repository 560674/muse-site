踩到的坑（每坑写：现象 → 原因 → 对读者的意义）

  1. 「备齐」这个词最容易说大：现象——资料包写完第一稿时，读起来像「已经能上架了」；原因——文字版齐了，但渠道、账号、实名、图尺寸四样都没落地，「备齐」只覆盖了文字这一层；对读者的意义——写资料包先写边界表：哪几项是齐的、哪几项是待查证、哪几项必须本人出面，三栏分开写，读者才不会把「资料包好了」误读成「马上能卖了」。
  2. 两套价格一合并就变虚假宣传：现象——XM-01 详情初稿差点把「工作包售价 49 元」与「模板内接单报价 199/699/1299 起」写成一句话；原因——前者是卖模板的价格，后者是买家拿去接单时发给新人的价格，主体完全不同；对读者的意义——详情页的价格表必须分两张表写，表头写清「这是卖模板的价格」与「这是模板里的接单报价」，合并写就是误导，哪怕数字全对。
  3. 图件清单不核磁盘就会抄错数：现象——帆布包组数字在 README 里已有，但白瓷杯组数字若凭印象写很容易张冠李戴；原因——两组样品是不同日期、不同品类的文件，只有 ls 实测才是证据；对读者的意义——资料包里的每一个数字都要有当轮的核对动作，抄旧文数字不算核对，第 03 篇「核对要留数字才算证据」在这里同样适用。
